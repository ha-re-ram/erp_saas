# Security Policy

We take the security of NexisERP and all merchant stores very seriously. Thank you for helping us keep the platform secure.

---

## Supported Versions

Only the latest active version of NexisERP receives security updates:

| Version | Supported |
| :--- | :--- |
| **v1.x.x (Active)** | 🥇 Yes |
| **v0.x.x (Legacy)** | ❌ No |

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**. Instead, report it responsibly so we can investigate and deploy a fix before it is publicly disclosed.

### How to Report
1. Email your findings directly to the project maintainer: **hareramkushwaha054@gmail.com**.
2. In your report, please include:
   * A detailed description of the vulnerability.
   * Step-by-step instructions or a proof-of-concept script to reproduce the exploit.
   * Any potential impact on customer data or store isolation boundaries.

---

## ⏱️ Response & Remediation SLA

*   **Acknowledgement**: We will acknowledge your report and start active triage within **24 hours**.
*   **Status Update**: We will keep you updated as we investigate, diagnose, and develop a patch.
*   **Disclosure**: Once a fix is developed and merged, we will coordinate public disclosures with you and give you proper credits in our release notes!
